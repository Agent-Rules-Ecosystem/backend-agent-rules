# ⚡ Skills Oficiales Compatibles — Backend

Catálogo de habilidades especializadas (`*-agent-skill`) de [`Agent-Rules-Ecosystem`](https://github.com/Agent-Rules-Ecosystem) recomendadas para este core.

## Skills de Dominio

| Skill | Comando | Descripción |
|---|---|---|
| `backend-auth-oauth-agent-skill` | `$auth` | OAuth2, JWT, OIDC y seguridad de sesiones |
| `backend-graphql-agent-skill` | `$gql` | Esquemas GraphQL, Dataloader N+1 y seguridad |
| `backend-stripe-agent-skill` | `$stripe` | Webhooks, suscripciones y Stripe Checkout |

## Skills Transversales Compatibles
- `firebase-auth-agent-skill`, `grapho-agent-skill`, `grapho-3d-visualizer-agent-skill`, `i18n-agent-skill`, `infra-agent-skill`, `monitoring-agent-skill`, `performance-agent-skill`, `security-agent-skill`, `telemetry-agent-skill`.

## Instalación como Submódulo

```bash
git submodule add git@github.com:Agent-Rules-Ecosystem/<nombre>-agent-skill.git .skill/<nombre>-agent-skill
```
